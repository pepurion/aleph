v0.1

The first version used during the Prologue. Based mostly on **Mothership 1e** (M1e) with some modifications mainly to character and class stats and battle systems. Here's the big stuff:

- Leveling system was remade to be more traditional and like one that we're used to. Originally there's no straight-line leveling in M1e.
- Made system less dependent on Stress meter, although it's still present
- Classes and class traits were reworked a bit
- Made battle system a little more dynamic with addition of Major and Minor Actions
- Added Trickster class to add a bit more variety to classes
- Added Voided class
- Completely remade character file, because I don't wanna fuck with original PDFs
- Space travel was made faster and easier
- Some things that are not that interesting or weren't used at all
